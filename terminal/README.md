# Windows Terminal snippet

Optional. The fetch and the prompt work without this. It only matches the **window** in the README screenshots: Tango Dark, acrylic glass, and **MesloLGL Nerd Font Mono**.

## Apply it

1. Install the font ([getting started](../docs/getting-started.md#4-a-nerd-font)).
2. In Windows Terminal, open Settings.
3. Click **Open JSON file** (near the bottom-left).
4. Merge the keys from [`settings.snippet.jsonc`](settings.snippet.jsonc) under `profiles.defaults`.
5. Save, then open a new tab.

If you already have a `font` or `colorScheme` block there, keep one of each — do not paste a second copy next to the old one.
